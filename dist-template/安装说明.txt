脱敏处理器 —— Notepad-- 插件 v1.0
==================================

功能
----
按自定义「关键词映射表」对当前文档一键脱敏/还原：
- 映射表：启用开关、原文、替换为，可增删、排序
- 脱敏：把文档中所有「原文」替换为「替换为」
- 还原：按映射反向替换回原文
- 单遍扫描 + 最长匹配，不会级联误替换
- 区分大小写开关、仅处理选中文本开关
- 自动生成随机替换串、批量粘贴（abc->xxx）、导入/导出（JSON/CSV/文本）
- 支持 Ctrl+Z 一步撤销
- 映射配置自动保存，重启 NDD 后仍在

支持环境
--------
- Windows 64 位版 Notepad--（Qt5 版本，如官方 v3.x 系列）
- 如果 NDD 目录里是 Qt6Core.dll（Qt6 版本），本插件不通用，需要重新编译
- 建议 NDD v3.8.2 及以上

安装
----
方法一（推荐）：
  双击 install.cmd，脚本会自动查找已安装的 Notepad-- 并复制插件，
  如果提示权限不足会弹出 UAC，点“是”即可。

方法二（手动）：
  把 desensitive_processor.dll 复制到 NDD 安装目录下的 plugin 文件夹，例如：
  C:\Program Files\Notepad--\plugin\
  绿色版则是解压目录下的 plugin 文件夹。

安装后重启 Notepad--，在菜单栏「插件」→「脱敏处理器」使用。

使用
----
1. 打开「脱敏处理器」，添加映射（例如 张三 -> 张*）
2. 点「脱敏」：当前文档所有“张三”替换为“张*”
3. 点「还原」：反向替换回“张三”
4. 配置会保存在 %APPDATA%\ndd-desensitive\mappings.json

跨电脑迁移映射
--------------
在插件窗口点「导出」保存为 JSON/CSV/文本，在另一台电脑点「导入」即可。

卸载
----
双击 uninstall.cmd；或手动删除 NDD 目录 plugin 下的
desensitive_processor.dll，然后重启 NDD。
如需同时清除映射配置，可删除目录 %APPDATA%\ndd-desensitive。
